# java-calculator-precourse

### 계산기

1. 사용자 입력  
    
    **Q. 사용자 입력 받는 법** 
    
    A. 사용자가 입력하는 값은 camp.nextstep.edu.missionutils.Console의 readLine()을 활용하여 입력 받습니다. 
    
2. 계산   
    
    2-1. 입력한 문자열에서 숫자를 추출 
    
    2.1.1. 커스텀 구분자 등록
    
    **Q. 커스텀 구분자가 문자열 앞에 없으면?**
    
    A. 커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용하기 때문에 문자열 앞에 위치하지 않은 경우엔 예외처리 한다.
    
    **Q. 커스텀 구분자가 숫자면?**
    
    A. 구분자는 숫자와 구분되어야 하기 때문에 커스텀 구분자가 숫자라면 판별할 수 없다. 예외처리 한다.
    
    **Q. 커스텀 구분자가 공백이면?**
    
    A. 공백도 구분될 수 있는 문자이기 때문에 커스텀 구분자로 사용한다.
    
    **Q. 커스텀 구분자가 문자열이면?** 
    
    A. 기능요구사항에서 커스텀 구분자는 문자로 명시해놓았기때문에 문자열이 커스텀 구분자라면 예외처리 한다.
    
    **Q. 커스텀 구분자가 기본 구분자와 동일하면?**
    
    A. 커스텀 구분자는 기본 구분자외에 지정해야하기 때문에 동일한 경우엔 예외처리 한다.
    
    2.1.2. 구분자로 문자열 분리
    
    **Q. 구분자와 숫자는 어떻게 구분하나요?**
    
    A. 문자열의 한 글자씩 확인하면서 구분자와 숫자를 판별한다. 
    
    2.1.3. 문자열 유효성 검사
    
    **Q. 구분자로 분리된 값이 숫자가 아니면?**
    
    A. 기능요구사항에서 구분자와 양수로 구성된 문자열이라고 명시했기 때문에 숫자가 아니거나 음수이면 예외 처리합니다.
    
    2-2. 덧셈 
    
    **Q. 숫자는 어떻게 더하나요?**
    
    A. 유효한 숫자만 더 최종 결과를 반환합니다.
    
3. 결과 출력 
    
    **Q. 결과는 어떤 형식으로 출력하나요?**
    
    A: 덧셈 결과가 X 라면 “결과: X” 형식으로 출력합니다.
    
    **Q. 결과가 출력되지 않을 수도 있나요?**
    
    A: 사용자가 잘못된 값을 입력할 경우 결과는 출력되지 않고 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료됩니다.
    

## 필요한 기능 정리

1. **문자열을 입력**
2. **구분자를 처리**
    - 커스텀 구분자를 추출
    - 커스텀 구분자가 숫자이거나 기본 구분자와 중복될 경우 예외 처리
    - 커스텀 구분자가 누락되거나 2글자 이상인 경우 예외 처리
3. **문자열을 분리하고 숫자를 검사**
    - 문자열을 구분자로 분리
    - 각 문자가 숫자인지 검사
    - 음수나 0이 포함된 경우 예외 처리
    - 숫자가 아닌 값이 포함된 경우 예외 처리
4. **덧셈 계산**
    - 숫자들의 합을 계산
